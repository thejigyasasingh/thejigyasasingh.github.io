Hydra Platform

An API gateway in Django that sits in front of a set of services. It checks who is calling, sends each request to a healthy instance, limits abuse and stops one failing service from slowing down the rest.

The path of one request

  1. Verify the callerClient token checked as an RS256 JWT against a JWKS key
  2. Find the routeRoutes cached in Redis and refreshed the moment an admin edits one
  3. Apply the rate limitRedis token bucket allowing 30 requests a minute per client and route
  4. Check the circuit breakerAfter 5 upstream failures in a row, requests fail fast with 503
  5. Reach a healthy serviceREST, uploads processed in the background with Celery, and WebSockets with Django Channels

Services register themselves with signed requests and send a heartbeat every 10 seconds, so traffic only goes to instances that are up.
